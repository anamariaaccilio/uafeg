# Decisiones de cierre (sesión autónoma 2026-11-20)

Una línea por decisión. Criterio: la opción más conservadora y científicamente defendible.

- 2026-11-20 · Cómputo pesado en Kaggle GPU (kernels privados); Khipu no se usa. CLI `kaggle` 1.7.4.5 no aceptaba el token nuevo → se instaló `kaggle` 2.2.5 en el `.venv` (Python 3.11) del Repo A.
- 2026-11-20 · Disco local (/home ≈ 360 MB libres): las imágenes se suben en dos datasets privados (`uafeg-v3-variants-a` = variantes v1+v3, `-b` = variantes v2), nombradas por SHA-256; las 807 originales HITL NO se suben: se usan desde el dataset público de Kaggle `humansintheloop/car-parts-and-car-damages` y cada archivo se verifica contra el hash congelado de v3 (si no coincide, el kernel aborta).
- 2026-11-20 · YOLOv8n-seg: la corrida CPU (416 px, 15 épocas) murió en la época 1 sin pesos. En GPU se entrena a escala estándar de Ultralytics: 640 px, ≤100 épocas, paciencia 20, batch 16, seed 0, base `yolov8n-seg.pt`. Selección del checkpoint = mejor fitness en validación; test HITL solo se evalúa después.
- 2026-11-20 · TruFor: las 3 788 imágenes ya procesadas en CPU no guardaron el puntaje global (`forensic.jsonl` nunca se escribió) → se rehacen las 5 240 en GPU, a resolución nativa (lado mayor ≤ 1 402 px, sin reescalar; la escala reducida de CPU ya no hace falta). Mapas guardados a 64 px de alto, como antes.
- 2026-11-20 · Dataset externo: CarDD (Wang et al., IEEE T-ITS 2023) vía el espejo de Kaggle `gabrielfcarvalho/cardd-with-yolo-annotations-images-labels`, licencia declarada CC BY-NC 4.0 (uso académico no comercial permitido). Se usa dentro del kernel (no se descarga localmente). Solo trae cajas → se reporta mAP de CAJA; el mAP de MÁSCARA externo queda NOT_RUN (no hay máscaras con licencia declarada). Otros espejos con máscaras tienen licencia "unknown" y se descartan.
- 2026-11-20 · Mapeo CarDD→ontología HITL fijado antes de evaluar: dent→dent, scratch→scratch, crack→crack, glass shatter→broken_part, lamp broken→broken_part, tire flat→excluida. Se reportan dos variantes: clases mapeadas y "daño" agnóstico de clase.
- 2026-11-20 · Agregador (G0/G1): además de S_apoyo/S_contra/S_desc/S_sim/F (máx. y media), conteos, c̄, q̄ y forense global, el vector incluye la fracción de afirmaciones negadas/indeterminadas y la incertidumbre media del relato, para no perder la negación cuando no hay detecciones visuales. Decidido antes de cualquier lectura de test; idéntico para G0, G1 y ablaciones.
- 2026-11-20 · Clasificador del agregador: 7 configuraciones por sistema (logística multinomial C∈{0.1,1,10}; gradient boosting lr∈{0.05,0.1}×profundidad∈{2,3}, subsample 0.8, ≤400 árboles con early stopping por NLL de validación). Mismo presupuesto (≤8) para todos los sistemas.
- 2026-11-20 · Ensamble de 5 semillas del agregador: la semilla controla el submuestreo del boosting; si gana la logística (convexa, determinista), las 5 semillas coinciden y se reporta desviación 0, sin inventar varianza.
- 2026-11-20 · Narrativo: en validación el tipo de daño exacto acierta 0.500 (1 129 reclamos) y por familia de la ontología HITL 0.689 → se aplica el mapeo: la confiabilidad r narrativa cuenta un acierto si la familia coincide y la polaridad es correcta. El modelo NLI no se reentrena.
