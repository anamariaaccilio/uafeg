**Resultados de validación** (preliminares: visual y forense todavía vacíos; no son resultados de la tesis)

*Cómo leer la tabla.* n = 1.256 reclamos de validación, de 110 fotos fuente. Cada celda muestra media ± desviación estándar entre las 5 semillas y, entre paréntesis, el valor del **ensamble** (promedio de las 5). Las probabilidades no están calibradas.
- **PR-AUC SUSPICIOUS** (↑ mejor): qué tan bien el sistema ordena los casos sospechosos por encima del resto. 1 es perfecto.
- **Brier** (↓ mejor): error cuadrático de las probabilidades. Mide si el sistema dice "80 %" cuando acierta el 80 % de las veces.
- **AURC** (↓ mejor): área bajo la curva riesgo–cobertura. Mide el error que queda cuando el sistema se abstiene primero en los casos donde está menos seguro.

*Sistemas.* B1 solo texto · B2 solo imagen (aquí, solo calidad de fuente) · B4 concatenar todo y pasar por una red simple · B5 fusión tardía (cada modalidad decide por separado y luego se combinan) · B7 DBF (fusión que descuenta la modalidad que contradice a las otras) · **B6** DeepSets (la evidencia como conjunto, sin relaciones) · **P1** grafo sin compuerta · **P2** UAFEG (grafo con compuerta de confiabilidad) · A1 = P2 sin compuerta (es P1) · A3 = P2 con DeepSets (es B6) · A4 = P2 sin atributos de arista · A5 = P2 entrenado sin los controles benignos C8.
